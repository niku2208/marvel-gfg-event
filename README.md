# 🦸 MARVEL × GFG — HEROES OF CODE

A cinematic, interactive and responsive event landing page created for the **GeeksForGeeks Student Chapter, Bennett University**.

The concept combines the visual energy of the Marvel universe with the world of coding, technology and innovation.

---

## ⚡ Project Overview

**Heroes of Code** is a Marvel-inspired tech event website designed to feel more like a real event experience than a traditional college website.

The website focuses on:

- 🎬 Cinematic visual design
- 🦸 Marvel-inspired hero experience
- 💻 Technology and coding theme
- ⚡ Interactive animations
- 📱 Fully responsive design
- 🎯 Clear event information
- 🚀 Registration call-to-action
- ✨ Smooth scrolling and visual effects

## ✨ Features

### 🎬 Cinematic Hero Section

The landing section includes:

- Large event title
- Marvel-inspired visual theme
- Event date and time
- Primary registration CTA
- Secondary event exploration CTA
- Animated background
- Hero statistics

---

### ⚡ Event Missions

The website contains multiple event cards representing different missions:

1. **Code of Heroes**
2. **Avengers Assemble**
3. **Hero's Challenge**

Each card includes:

- Mission number
- Category
- Description
- Interactive hover effect
- Call-to-action

---

### 🦸 Heroes Section

A character showcase section introduces different types of tech heroes:

- The Strategist
- The Builder
- The Leader
- The Innovator

Each character card has a visual image and hover interaction.

---

### 🕒 Event Timeline

The timeline shows the planned event journey:

- 09:30 AM — Arrival
- 10:00 AM — Assembly
- 11:00 AM — The Challenge
- 01:00 PM — Final Showdown

---

### ⏳ Countdown Timer

A JavaScript-powered countdown timer displays:

- Days
- Hours
- Minutes
- Seconds

The countdown is configured for:

**27 September 2026 — 10:00 AM IST**

---

### 📝 Registration Form

The website includes a frontend registration form with:

- Name
- Email
- College / Institution

The form performs basic client-side validation and displays a confirmation message.

> Note: The current registration form is frontend-only and does not store submissions in a database.

## 🎨 Design Direction

The visual direction is based on a dark cinematic interface with strong red accents.
